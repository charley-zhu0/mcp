# 更新项目 README.md

请扫描当前仓库中的所有 MCP 服务目录，收集每个服务的信息，然后更新项目根目录的 `README.md` 文件。

## 扫描规则

1. **识别 MCP 服务**: 查找所有包含 `pyproject.toml` 或 `package.json` 的子目录，且其中定义了 MCP 服务入口
2. **信息来源**: 
   - 从服务的 `README.md` 文件获取简要说明
   - 从源代码（如 `server.py` 或 `index.ts`）获取工具（tools）定义
   - 从代码或文档获取环境变量配置参数

## 需要收集的信息

对于每个 MCP 服务，收集以下内容：

1. **服务名称**: 从目录名或 pyproject.toml/package.json 获取
2. **简要说明**: 一句话描述服务功能
3. **提供的工具**: 列出所有 `@mcp.tool()` 装饰的函数或等效定义
4. **配置参数**: 环境变量及其说明
5. **Claude Desktop 配置示例**: JSON 配置片段
